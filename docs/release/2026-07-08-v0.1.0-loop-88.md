## Summary

- Added `web-universal-cloud-browser-zip` as the canonical cloud browser web
  ZIP package target.
- Aligned the release package target set across `sdkwork.workflow.json`, release

## Commercial Readiness Blockers

SDKWork IM is still not commercially releasable in this loop.

`pnpm.cmd check:commercial-readiness` now passes through the implementation
checks that previously reached the gateway OpenAPI index failure, then blocks
at `appReleaseAssessment` with 55 real release-evidence blockers:

- All 13 enabled direct distribution packages still have `checksum=null` while
  `security.checksumRequired=true`.
- All 13 enabled direct distribution packages still lack signature evidence
  while `security.signatureRequired=true`.
- All 13 enabled direct distribution packages still lack SBOM evidence while
  `security.sbomRequired=true`.
- All 13 enabled direct distribution packages still lack provenance or
  attestation evidence while `security.sbomRequired=true`.
- `chat-primary-icon`, `chat-web-screenshot`, and `chat-catalog-preview` still
  carry `metadata.generatedPlaceholder=true`.

These blockers require real artifacts, checksums, signatures, SBOMs,
provenance or attestations, and real media assets. They must not be replaced by
placeholder strings, fake refs, empty objects, empty arrays, or documentation
claims.
