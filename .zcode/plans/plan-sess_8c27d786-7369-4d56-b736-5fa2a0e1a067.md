## 目标
将 im-h5 tabbar「智能体」页（`/agents`）从 mock 实现替换为真实逻辑：在 sdkwork-agents 的 H5 包（`@sdkwork/agents-h5-agents`）中实现市场/搜索页面，集成进 sdkwork-im-h5，并接通真实数据与会话。

## A. sdkwork-agents-h5（sdkwork-agents 仓库，实现真实页面）

1. **新增 `src/pages/AgentMarketplaceMobileView.tsx`**（智能体市场 tab 页）
   - 设计对齐（以 im-h5 原 `AgentList` UI 为基准）：分类横滑栏（点击居中滚动）、右侧搜索入口（渐变遮罩）、卡片列表（圆形头像/名称/描述两行截断/users·author meta）、底部浮动「创建智能体」按钮、下拉刷新 + 骨架屏
   - 真实逻辑：
     - `agentService.listAgentsPage({ scope: 'market', page, pageSize: 20 })` 分页加载 + 无限滚动 + 下拉刷新
     - 分类 = 设计固定分类（精选/学习/工作/创作/生活/娱乐/情感/游戏/编程/绘画/拍照问）+ 从市场数据动态合并的 `categoryId`；客户端按分类过滤（后端 `agents.list` 仅支持 page/pageSize/q/scope/includeDeleted，无分类参数）
     - 点击卡片 → `onStartChat(agent)`（带 name/welcomeMessage）；创建按钮 → `onCreateAgent`
2. **新增 `src/pages/AgentMarketplaceSearchView.tsx`**：真实搜索（`listAgentsPage({ scope:'market', q })`，300ms 防抖）+ 热门搜索建议 chips（设计保留，仅作搜索建议）+ 结果列表
3. **`i18n/mobileAgentTexts.ts`**：补充市场页/搜索页 zh/en 文案
4. **`src/index.ts`**：导出新页面与 props 类型
5. **独立 App（`src/App.tsx`）**：增加移动市场页/搜索页路由，便于独立运行验证

## B. sdkwork-im-h5（本仓库，集成）

1. **`routeCatalog.ts`**：新增 `agentsChat` 路由定义（`/agent/chat/:agentId`，moduleId `agents`，stack）
2. **`contactsModule.tsx`**：`/agents` 渲染 `AgentMarketplaceMobileView`、`/agent-search` 渲染 `AgentMarketplaceSearchView`（lazy 引入 `@sdkwork/agents-h5-agents`）；tab 导航贡献保持不变（module 归属与 tab 顺序约束：chat→agents→workspace→discover→me）
3. **`agentsModule.tsx`**：
   - 新增 `/agent/chat/:agentId` 路由 → `AgentChatView`（真实 sessions 会话）
   - `MyAgentsView` 接入 `onStartChat` → 跳转 `/agent/chat/:id`（替换「即将上线」toast）
   - 市场页 `onStartChat` → 同一路由（location.state 携带 agent name/welcome）
4. **移除 mock**：删除 `sdkwork-im-h5-contacts` 的 `pages/AgentList.tsx`、`pages/AgentSearch.tsx`、`services/AgentService.ts`，更新 `src/index.ts` 导出（与仓库既有 mock 清理模式一致：git status 已删除 AgentCreate.tsx/MyAgentsPage.tsx 等同型文件）
