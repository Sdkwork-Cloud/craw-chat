# 「我的智能体」CRUD — 在 sdkwork-agents-h5 实现、集成进 sdkwork-im-h5

## 背景与结论（已探索确认）

- 智能体后端契约在 `sdkwork-agents` 仓库：`/app/v3/api/ai/agents` CRUD（list/create/retrieve/update/delete 软删除/restore），SDK 为 `@sdkwork/agents-app-sdk`（已注册进 IM workspace，`client.ai.agents.*`，baseUrl 自动补 `/app/v3/api` 前缀）。
- `@sdkwork/agents-h5-agents`（agents 仓库 h5 能力包）**已实现真实 CRUD 服务**（`agentService` + `configureAgentService(getAgentClient)` 宿主注入钩子），但页面为 **PC 双列布局**（AgentView/CreateAgentView），**没有移动端单列视图**；i18n 硬编码中文。
- 集成先例已验证：`sdkwork-im-pc` 已按同一模式集成 `agents-pc-agents`（workspace glob + 依赖 + `configureAgentService` 注入 + vite alias）；IM H5 自身集成 mobile-react 能力包模式一致（shell module lazy import + bootstrap configure 注入，禁止裸 HTTP/自建 SDK client）。
- IM H5 现状：`/me/agents`（user 包 `MyAgentsPage`）、`/agent/create`、`/agent/edit/:id`（contacts 包 `AgentCreate`）均为 **localStorage mock**，将移除替换。
- 已确认的决策：① 移动端智能体视图在 agents 仓库实现、IM 侧只集成；② 仅做「我的智能体」CRUD，市场页保持现状；③ 后端不可达时错误态+重试，不回退 mock。

## Part A — sdkwork-agents 仓库（智能体 H5 实现，遵循积木架构）

### A1. AgentService 增强（`apps/sdkwork-agents-h5/packages/sdkwork-agents-h5-agents/src/services/AgentService.ts`）
- 新增 `restoreAgent(id)` → `ai.agents.restore(id, { requestedAt })`（软删除恢复）。
- `listAgentsPage` 支持 `includeDeleted`（SDK 参数已存在），scope=`mine` 时一并取已删除条目。
- `AgentConfig` 补充 `status`/`deletedAt`/`updatedAt`/`version` 字段（映射自 `AgentRecord`），支撑状态徽标与已删除分组。
- 删除保持软删除语义（现有 `deleteAgent`）。

### A2. 新增移动端「我的智能体」列表视图 `src/pages/MyAgentsView.tsx`（对齐微信/豆包移动端专业设计）
- 单列列表：56px 圆角头像 + 名称 + 状态徽标（草稿/已发布/已停用/已删除）+ 简介两行截断。
- 完整状态机：加载骨架 → 错误态+重试按钮 → 空态（引导创建）→ 列表。
- 分页：一次一页（`PAGINATION_SPEC` §8），触底/按钮「加载更多」，维护 hasMore。
- 操作：条目「⋯」或长按弹 ActionSheet（编辑/删除），删除走确认弹窗（提示可恢复）；**已删除分组**内条目提供「恢复」入口。
- 受控回调 props（与现有 AgentView 一致，不持路由）：`onStartChat` / `onCreateAgent` / `onEditAgent(id)` / `onBack?`。
- 内置 zh/en 轻量文案表（key 映射+`{{}}` 插值，同现有 `messageInputI18n` 模式），默认 zh。

### A3. 新增移动端创建/编辑视图 `src/pages/CreateAgentMobileView.tsx`
- 移动端单列表单：头像、名称、简介、人设系统提示词、模型+温度、长记忆开关、开场白、快捷提问（suggestedPrompts）。
- 编辑模式经 `initialAgentId` 回填（复用 `agentService.getAgent`）；提交走 `createAgent`/`updateAgent`（含版本乐观锁），「保存草稿」「发布」（`publishAgent`）。
- 复用现有 `EditBasicInfoModal`（名称/简介/头像）、`AgentDefaults`、`toast`；知识库/工具/语音等高级项在未注入适配器时隐藏（后续能力接入）。
- 加载/错误态：骨架、错误 toast、提交中禁用；文案同 A2 文案表。

### A4. 导出与本地契约
- `src/index.ts` 新增导出：`MyAgentsView`、`CreateAgentMobileView`、`restoreAgent` 相关类型。
- 更新 `apps/sdkwork-agents-h5/specs/component.spec.json` 的 publicExports（如存在该字段）。

## Part B — sdkwork-im 仓库（集成进 sdkwork-im-h5）

1. **workspace 注册**：`sdkwork-im/pnpm-workspace.yaml` 追加 3 行：`../sdkwork-agents/apps/sdkwork-agents-h5/packages/{sdkwork-agents-h5-agents, sdkwork-agents-h5-commons, sdkwork-agents-h5-core}`（照抄 pc 包先例）。
2. **依赖声明**：`apps/sdkwork-im-h5/package.json` 加 `@sdkwork/agents-h5-agents: workspace:*`；`packages/sdkwork-im-h5-core/package.json` 加 `@sdkwork/agents-app-sdk: workspace:*`。
3. **IM 侧 SDK client 端口**：新建 `packages/sdkwork-im-h5-core/src/sdk/agentsAppSdkClient.ts`（IM 模式：`createAgentsAppSdkClientConfig`/`init`/`get`/`reset`，tokenManager 用 IM 自己的），`sdk/index.ts` 导出。
4. **bootstrap**：`src/bootstrap/environment.ts` 加 `agentsAppApiBaseUrl`（`SDKWORK_AGENTS_APP_API_BASE_URL`/`VITE_SDKWORK_AGENTS_APP_API_BASE_URL`，fallback 到 `sdkGatewayApiBaseUrl`）；`src/bootstrap/sdkClients.ts` 构造 agents client 入 `H5SdkClientComposition`；`src/bootstrap/index.ts` 调 `configureAgentService(() => sdkClients.agentsAppSdkClient)`（im-pc 同款注入）。
5. **shell 模块**：`contracts.ts` 的 `ImH5ModuleId`、`moduleCatalog.ts` 的 `ALL/DEFAULT` 加 `"agents"`；新建 `modules/agentsModule.tsx`（lazy import `@sdkwork/agents-h5-agents` 的 `MyAgentsView`/`CreateAgentMobileView`，页面挂 `ToastContainer`）；`moduleRegistry.ts` 注册。
6. **路由切换**：`routeCatalog.ts` 新增 `agentsMyAgents`(`/me/agents`)、`agentsCreate`(`/agent/create`)、`agentsEdit`(`/agent/edit/:id`)，moduleId=`agents`；从 `userModule.tsx`/`contactsModule.tsx` 移除对应智能体路由与 lazy 组件。
7. **移除 IM 自研 mock**：删除 user 包 `MyAgentsPage.tsx` 及导出、contacts 包 `AgentCreate.tsx` 及导出；`AgentService.ts` 删除已被替代的 my-agents 方法（保留市场页仍在用的 `getAgents`/`getCategories`/`getHotSearches`/`createAgentChat`）。Me 页「智能体」入口保持指向 `/me/agents`。
8. **vite alias**：`vite.config.ts` 按既有模式加 agents-h5 三包 alias（指向 `../../../sdkwork-agents/apps/sdkwork-agents-h5/packages/*/src/index.ts`）。
9. **i18n**：`commons/src/locales/{zh,en}/agents.json` 补路由 titleKey 与页面级文案（`agents.my_agents.*`、`agents.create.*` 等）；页面内文案由 agents-h5 提供。

## Part C — 验证（最窄范围优先）

- agents 仓库：`apps/sdkwork-agents-h5` typecheck/构建。
- IM 仓库：`apps/sdkwork-im-h5` typecheck/lint/build；`pnpm install`（workspace 变更）。
- 跨仓库校验：`check-frontend-composition.mjs`（积木架构）、`check-pagination.mjs`（列表分页）、`test:sdkwork-workspace-structure-standard`（workspace/包结构）。
- 手工冒烟：`pnpm dev` 后「我 → 智能体」列表/创建/编辑/删除/恢复流程。

## 范围与风险说明

- 列表条目「开始聊天」本次为占位（toast 提示），真实会话属 IM dispatch 流程（边界 spec 另一契约），后续接入 `AgentChatView`。
- agents-h5 四个包为 `private` + exports 指向 src：走 workspace glob + vite alias（im-pc 已验证可行）。
- 知识库/语音/工具等高级配置项在未注入适配器时隐藏，后续按需注入。
- 不改动 agents 后端契约与生成 SDK；不动 IM 数据库表。
