# 订单/收银台/会员订阅/充值 国际化全面修复计划

## 背景与问题定位

IM H5 实际使用的页面链路：
- 订单列表/收银台/订单详情 → `sdkwork-order/.../sdkwork-order-mobile-react-orders`
- 会员订阅/算力积分购买 → `sdkwork-order/.../sdkwork-order-h5-subscription`
- 备用（未接线）→ `sdkwork-membership/.../sdkwork-membership-mobile-react-subscription`（经 `@sdkwork/im-h5-vip` 导出）
- 资源宿主 → `sdkwork-im/apps/sdkwork-im-h5/packages/sdkwork-im-h5-commons`

### 已确认的问题
1. **订单显示英文 "Membership"**：`order.subject` / `item.title` 直接渲染后端值（OrderCard.tsx:35,59、OrderItemsCard.tsx:17,30、OrderDetail.tsx:83、CashierPage.tsx:537）。membership 订单后端 subject 为英文 "Membership"；充值订单 subject 为代码标识 `"points_recharge"`（SubscriptionPurchaseService.ts 创建订单时直接传入）。UI 层无本地化映射。
2. **`subscription.*` namespace 无资源**：IM host 的 i18n.ts 未注册 subscription namespace，`sdkwork-order-h5-subscription` 全部 `t("subscription.xxx", fallback中文)` 在英文环境不翻译。
3. **充值相关硬编码中文**：TokenBankPurchasePage 的 `toLocaleString("zh-CN")`、SubscriptionCatalogPort 拼装 `"${points} 算力积分"`、VipSubscriptionPage FALLBACK_BENEFITS 硬编码。
4. **备用包全部硬编码**：TokenRechargePage/RechargeTabsHeader/RechargeTabContent/PlanTabContent/CouponTabContent/RechargeFooterBar 无 t()；VipSubscriptionPage 套餐/权益硬编码；标题用 `auto_*` 哈希 key。
5. **vip.json 资源损坏**：en/zh 完全相同（en 未翻译）；`auto_*` 哈希 key 不规范、大量死 key；`auto_n2c8bf51c`/`auto_n1b21cb20` 的值是代码片段字符串（无任何引用）。

## 修改内容

### A. `sdkwork-order` → `sdkwork-order-mobile-react-orders`（订单标题本地化，核心）
1. 新增 `src/services/orderTitle.ts`：
   - `localizeOrderSubject(subject, t)`：归一化（trim/lowercase）后按已知映射表匹配 —— `membership`/`membership subscription`/`vip` → `t("orders.subject_membership", subject)`；`points_recharge`/`points recharge` → `t("orders.subject_points_recharge", subject)`；`token_bank_recharge` → `t("orders.subject_token_bank_recharge", subject)`；未知值原样返回（不破坏）。
   - `localizeOrderItemTitle(title, t)`：同一映射逻辑用于商品名。
2. 应用到 5 处渲染点：OrderCard（subject + item.title）、OrderItemsCard（subject + item.title）、OrderDetail（subject）、CashierPage（subject）。
3. 新增 `orderTitle.test.ts` 单测。

### B. `sdkwork-order` → `sdkwork-order-h5-subscription`（订阅/充值页打磨）
1. `SubscriptionCatalogPort.ts`：`displayName` 移除硬编码中文拼装，改为纯数值（`String(points)`），由 UI 用 `t("subscription.points_display", "{{points}} 算力积分", { points })` 渲染。
2. `TokenBankPurchasePage.tsx`：`toLocaleString("zh-CN")` → `toLocaleString(i18n.language)`（3 处）；`displayName` 渲染接入 `points_display`。
3. `VipSubscriptionPage.tsx`：FALLBACK_BENEFITS 改为 key + fallback 形式接 t()。

### C. `sdkwork-im-h5-commons`（IM host 资源宿主）
1. 新增 `locales/zh/subscription.json` 与 `locales/en/subscription.json`：收录 h5-subscription 包全部 `subscription.*` keys（vip_title、token_bank_title、all_plans、loading_packages、load_failed、empty_packages、loading_plans、empty_plans、recommended、duration_days、vip_benefits、creating_order、confirm_payment、token_bank_balance、points_unit、points_display、grant、bonus、agreement、token_notice、select_plan_first、coupon_* 系列）。
2. `i18n.ts`：注册 `subscription` namespace（zh/en）。
3. `orders.json`（en/zh）：新增 `subject_membership`、`subject_points_recharge`、`subject_token_bank_recharge`。
4. `vip.json`（en/zh）：
   - 删除无引用的 `auto_*` 死 key（含代码片段 key）。
   - 在用 key 规范改名：`vip.title`、`vip.banner_title`、`vip.banner_desc`、`vip.plan_title`、`vip.benefits_title`、`vip.pay_coming_soon`、`vip.open_now`。
   - 新增备用包修复所需 keys：`vip.recharge_title`、`vip.tab_recharge`、`vip.tab_plan`、`vip.tab_coupon`、`vip.balance_title`、`vip.select_amount`、`vip.bonus_send`、`vip.includes`、`vip.buy_now`、`vip.receive_now`、`vip.confirm_pay`、`vip.valid_until`、`vip.min_spend`、`vip.no_threshold`、`vip.plan_month/quarter/year`（名称/描述/角标）、`vip.benefit_identity/safety/priority`。
   - **en 版本真正翻译为英文**（不再复制中文）。

### D. `sdkwork-membership-mobile-react-subscription`（备用包打磨，与 C 配套）
1. `TokenRechargePage.tsx`：标题接 `vip.recharge_title`；TOKEN_AMOUNTS bonus 数据改为数值、文案走 `vip.bonus_send`；TOKEN_PLANS/COUPONS 名称/描述改为 `key + fallback` 形式；toast 接 t()。
2. `RechargeTabsHeader.tsx`：三个 tab 接 `vip.tab_recharge`/`vip.tab_plan`/`vip.tab_coupon`。
3. `RechargeTabContent.tsx`：`当前 Token`/`选择充值金额`/bonus 接 t()。
4. `PlanTabContent.tsx`：`内含`/`立即购买`/plan 名称描述接 t()。
5. `CouponTabContent.tsx`：`满 X 元可用`/`无门槛使用`/`有效期至`/`立即领取`/券名接 t()。
6. `RechargeFooterBar.tsx`：`确认支付 ¥X` 接 `vip.confirm_pay`。
7. `VipSubscriptionPage.tsx`：VIP_PLANS 名称/描述/badge、VIP_BENEFITS 接 t()；标题改用 `vip.title`。
8. `VipPlanSelector.tsx`/`VipBanner.tsx`/`VipBenefitsGrid.tsx`/`VipFooter.tsx`：`auto_*` key 全部替换为规范 key（vip.plan_title、vip.banner_title、vip.banner_desc、vip.benefits_title、vip.pay_coming_soon、vip.open_now），套餐名/badge/权益名接 t()。
