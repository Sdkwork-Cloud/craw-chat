# 目标

移动端访问登录界面时，必须使用移动端登录界面（zip 设计稿的登录/注册体系）。当前：
- **sdkwork-im-h5**（移动端应用）：登录已是移动端界面（上一任务完成）✓
- **sdkwork-im-pc**（桌面 Web 应用，BrowserRouter）：登录固定渲染 auth-pc-react 的 PC 界面（viewportMode="fixed" + 桌面窗口装饰），**移动设备访问时没有移动端登录页** ← 本次要补

实现：**设备自适应登录路由** —— 移动端（UA/触屏/窄视口）→ 渲染 `@sdkwork/iam-h5-auth` 的移动端登录体系（zip 设计，含登录/验证码登录/手机号注册/找回密码/条款/第三方/组织选择/扫码完整逻辑）；桌面端 → 保持现有 PC 登录。复用上一任务构建的可复用移动端登录体系，并完善其可复用性。

# Part 1 — sdkwork-iam `@sdkwork/iam-h5-auth`：完善可复用入口

1. **新增 `src/utils/viewport.ts`**：`isSdkworkMobileAuthViewport(env?)` —— 移动端检测（手机 UA 正则 + `maxTouchPoints > 0` + `max-width: 768px` 窄视口；`env` 可注入以便单测）。逻辑：`mobileUA || (touch && narrow)`。

3. **`src/index.ts`** 导出新组件与工具。
4. **测试**：`tests/auth-h5.viewport.test.ts`（注入环境参数覆盖 mobile UA / 桌面 UA / touch+narrow / 纯桌面），`tests/auth-h5.routes.test.tsx`（渲染 Routes 组件：`/auth/login` 显示登录屏、`/auth/oauth/callback` 显示回调屏——MemoryRouter 包一层）。
